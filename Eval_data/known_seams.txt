# known_seams.txt
#
# Places where readers and scholars have long seen a change in a book:
# a new source, a new section, a change of language, speaker or setting.
# find_shifts.py checks whether the data finds a change at each of them.
#
# This list was drawn up from general knowledge of biblical scholarship,
# not from Word Atlas data, and it is meant to be edited: add a seam you
# know of, remove one you doubt, correct a verse.  One seam per line:
#
#     Book chapter:verse    a short note
#
# The verse is the first verse AFTER the change.  Lines starting with #
# are notes and are skipped.
