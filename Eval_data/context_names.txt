# context_names.txt
#
# Names for the contexts the data found (discover_contexts.py).  The data
# finds and numbers the contexts; naming them is the reader's judgement.
#
# One context per line:
#
#     layer testament number | name | the words that mark it
#
#   layer      content (every word) or orientation (the small words)
#   testament  Old or New
#   number     the context's number in the report it was named from
#   words      the context's marking words when it was named; they let
#              name_contexts.py find the same context again if a later run
#              numbers the contexts differently
#
# After editing, run:   python3 Eval_data/name_contexts.py save
# which stores the names in metadata.db and refreshes metadata_backup.sql.
# Lines starting with # are notes and are skipped; a name of ? is not yet named.
